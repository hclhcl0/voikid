# Little Market artwork

`storefront.webp` is an original environment generated with the built-in imagegen tool, then converted to WebP with sharp. No third-party artwork was used as a generation reference. Characters use the project's original flower, star and rainbow sprites. Product icons use the existing Fluent Emoji/Twemoji renderer and licenses.

Prompt: A professional mobile casual game environment, landscape 1536x1024, adorable pastel fantasy village store viewed straight on. Premium painted 2.5D illustration, warm lighting, mint/peach striped awning, cream wall, teal window, shelves and baskets at edges. Clean mint space in upper center for real character/UI overlays, honey wooden counter in bottom third, flowering plants and fairy lights in corners. No people, words, logos, buttons or watermarks.

The real UI is rendered separately and is keyboard accessible. This game uses a curated 20-item vocabulary set, with matching Vietnamese meanings and product icons. Each session has eight customers; rewards are persisted via profile progress once per session.
