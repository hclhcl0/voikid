# Original pastel chibi character set

Generated with the built-in image_gen tool for this project, October 11, 2026.
These original designs were generated from text without CraftPix reference images.
Source sheets: flower-sheet.png, star-sheet.png, rainbow-sheet.png.
Each sheet has 4 columns and 4 rows: idle, attack, hurt, victory.
The runtime uses extracted WebP rows under ../chibi, preserving transparency.
Generated four-frame sequences have some pose/scale variation; they are stylized
animations, not hand-authored production rig animations. No dying pose is supplied;
the runtime holds the last hurt frame for a defeated original character.
